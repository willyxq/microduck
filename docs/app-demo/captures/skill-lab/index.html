模型页点下载 / 卸载。互动页只出现已启用的能力。点行走用 Cream 脚；点轮滑走换成四只被动轮。下面是刚跑完的实机记录。

1. 机体必须对上

点「行走」时 health.body = walk。点「轮滑走」时 health.body = rollers。摄像头跟的是同一只鸭子。

2. 模型页：空仓 → 装满 → 再卸
